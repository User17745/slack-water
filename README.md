# Slack Water *(working title)*

A pocket-sized tactics roguelite where everyone moves at once. Tidepool critters
fight the Murk on a 6×6 rockpool: you play alone in 15-minute runs, or face to face
with a friend on one phone or two.

- **Completely free.** No ads, no purchases, no accounts, no tracking.
- **Fully offline.** Works in airplane mode, forever.
- **Local 2-player.** Pass one phone back and forth, or link an iPhone and an
  Android phone over Wi-Fi or a hotspot by scanning a QR code.
- **Open source.** Code under MIT, art under CC BY 4.0.

## Status

**Pre-production.** The game design is written; no game code exists yet. Next up:
a paper prototype of the rules and a two-phone pairing test app.
